# AYNI

Plataforma web de gestión académica y seguimiento del estudiante · Grupo 02 · Aplicaciones en la Nube (UNS).

## Para iniciar

Para iniciar, ejecuta `1. INICIO/AYNI.bat` (Windows) o `1. INICIO/AYNI.sh` (Linux). El sistema está explicado en `1. INICIO/MANUAL/Manual de usuario.pdf`.

| Sistema | Qué ejecutar |
|---|---|
| Windows | `1. INICIO/AYNI.bat` (doble clic) |
| Linux | `bash "1. INICIO/AYNI.sh"` |

La primera vez elige la opción **1** del menú. Las credenciales están en `1. INICIO/CREDENCIALES.txt`.

**Versión web:** https://ayni.ruta-practica.com/
